# Строительная климатология — СП 131.13330.2025

Streamlit-приложение: справочник климатических параметров по 551 пункту СП 131.13330.2025.

- Таблица и карта станций с поиском и фильтрами (субъект, t пятидневки, климатический подрайон,
  сейсмичность), поиск ближайших станций по координатам площадки.
- Карточка станции по разделам СП: табл. 5.1, 6.1, 7.1, 8.1, 9.1, 10.1, 11.1, 12.1,
  13.1, 13.2 (интерполяция по широте), 14, 15.1 (астрономический расчет), 16.1, 16.2, А.1, Б.1.
- Справочно: значения СП 131.13330.2020, СП 131.13330.2018, СНиП 23-01-99* (серым) для
  табл. 5.1, 6.1, 7.1, 11.1; вес снегового покрова по Прил. К СП 20.13330.2016; сейсмичность
  ОСР-2016 по ближайшему пункту перечня Прил. А СП 14.13330.2018.
- Производные: условия табл. А.1 (климатический подрайон, условно), Mt, нормативная и расчетная
  глубина промерзания по СП 22.13330 (п. 5.5.3, 5.5.4).
- Экспорт карточки в Excel и Word, экспорт отфильтрованного списка в Excel.

## Запуск

```bash
pip install -r requirements.txt
```

```bash
streamlit run app.py
```

Публикация в интернете — см. [ИНСТРУКЦИЯ_ПУБЛИКАЦИЯ.md](ИНСТРУКЦИЯ_ПУБЛИКАЦИЯ.md).

## Данные

`data/*.csv` собраны скриптом `tools/build_data.py` из трёх xlsb («СП131_13330_2025 на одной
странице с картами», «Живые климатические карты СП20», «Живые карты ОСР-2016») и сверены
`tools/verify_sources.py`:

- 52 345 значений `stations.csv` совпадают с листом «Сводная» один в один;
- 69 из 70 значений однолистовой формы (Барнаул) совпадают; расхождение — осадки за декабрь:
  в форме 13 мм, в «Сводной» 29 мм; годовая сумма 423 мм сходится только с 29 мм
  (ошибка формы в исходнике, в приложении — 29);
- годовые суммы осадков и средние температуры согласуются с месячными для всех станций;
- табл. 13.1 и 13.2 (лист «Расчетка») для Барнаула совпадают с формой, кроме строки «С» табл. 13.2:
  в форме она сдвинута на месяц (ошибка формы, в приложении — по таблице);
- склонение Солнца в табл. 15.1 считается по алгоритму NOAA; приближенные значения формы
  отличаются до 0,8°;
- 124 станции СП-2025 отсутствуют в прежних редакциях (новые пункты) — для них справочных
  значений нет.

`tools/smoke_test.py` — прогон карточек всех станций и экспорта без интерфейса.
