# Как бесплатно опубликовать приложение в интернете (пошагово, для новичка)

Итог: у приложения будет адрес вида `https://sp131-klimat.streamlit.app`, который открывается
в любом браузере, на компьютере и телефоне. Платить ничего не нужно, сервер не нужен.

Понадобятся две бесплатные учётные записи:

- **GitHub** — хранилище файлов приложения;
- **Streamlit Community Cloud** — бесплатный хостинг, который берёт файлы с GitHub и запускает их.

Время: 15–20 минут в первый раз.

---

## Шаг 0. Что публикуем

Папка `sp131-climate`. В интернет нужно отправить **всё её содержимое**:

```
app.py                  — само приложение
core.py                 — расчёты, разделы, экспорт
requirements.txt        — список библиотек (хостинг установит их сам)
data/                   — данные: stations.csv, prev_editions.csv, osr2016.csv, sp20_snow.csv
.streamlit/config.toml  — оформление (светлая тема, без лишнего)
tools/                  — скрипты пересборки и перепроверки данных (для работы не обязательны)
README.md, ИНСТРУКЦИЯ_ПУБЛИКАЦИЯ.md
```

Исходные файлы `.xlsb` публиковать **не нужно** — приложение работает на CSV из папки `data`.

Папку `.claude` загружать не нужно (это служебная папка, если она есть).

## Шаг 1. Регистрация на GitHub

1. Откройте https://github.com/signup
2. Введите почту, придумайте пароль и имя пользователя (латиницей, например `ivanov-eng`).
3. Подтвердите почту кодом из письма.
4. На вопросы анкеты можно отвечать как угодно или нажать **Skip**. Тариф — **Free**.

## Шаг 2. Создание хранилища (репозитория)

1. Войдите на GitHub, справа вверху нажмите **«+»** → **New repository**.
2. **Repository name**: `sp131-climate` (только латиница, без пробелов).
3. Выберите **Public** (публичный — самый простой вариант для бесплатного хостинга).
4. Галочки «Add a README» и прочие **не ставьте**.
5. Нажмите **Create repository**.

## Шаг 3. Загрузка файлов

1. На странице нового репозитория нажмите ссылку **uploading an existing file**
   (или кнопку **Add file → Upload files**).
2. Откройте папку `sp131-climate` в Проводнике, выделите **всё содержимое** (Ctrl+A)
   и перетащите в окно браузера. Папки `data`, `.streamlit`, `tools` перетаскиваются целиком.
   - Важно: перетаскивать нужно **содержимое** папки, а не саму папку `sp131-climate`.
     Файл `app.py` должен оказаться в корне репозитория.
   - Если папка `.streamlit` не видна в Проводнике: Вид → Показать → Скрытые элементы.
     Без неё приложение тоже заработает, просто с оформлением по умолчанию.
3. Дождитесь, пока все файлы загрузятся (список внизу окна).
4. Внизу нажмите зелёную кнопку **Commit changes**.
5. Проверьте: в репозитории должны быть видны `app.py`, `core.py`, `requirements.txt`,
   папки `data`, `.streamlit`, `tools`.

## Шаг 4. Регистрация на Streamlit Community Cloud

1. Откройте https://share.streamlit.io
2. Нажмите **Continue to sign-in** → **Continue with GitHub**.
3. Разрешите доступ (**Authorize streamlit**).
4. Если попросят заполнить профиль (имя, почта) — заполните и продолжите.

## Шаг 5. Запуск приложения

1. Справа вверху нажмите **Create app**.
2. Выберите **Deploy a public app from GitHub** (или «Yup, I have an app»).
3. Заполните:
   - **Repository**: `ваше-имя/sp131-climate`
   - **Branch**: `main`
   - **Main file path**: `app.py`
   - **App URL**: придумайте адрес, например `sp131-klimat` → получится `https://sp131-klimat.streamlit.app`
4. Откройте **Advanced settings** → **Python version**: выберите **3.12** → **Save**.
5. Нажмите **Deploy**.
6. Подождите 2–5 минут: справа будет идти журнал установки. Когда он закончится,
   откроется приложение.

Готово. Ссылку можно отправлять коллегам — авторизация не нужна.

## Как обновить приложение

Любое изменение файлов на GitHub автоматически перезапускает приложение (через 1–2 минуты).

- Заменить файл: в репозитории **Add file → Upload files**, перетащить новый файл с тем же
  именем → **Commit changes**.
- Поправить текст прямо в браузере: открыть файл → значок карандаша → изменить → **Commit changes**.

## Как обновить данные (если вышли новые xlsb)

На своём компьютере, в папке `sp131-climate`:

```bash
pip install pyxlsb pandas msoffcrypto-tool
```

```bash
python tools/build_data.py "путь\СП131...2025.xlsb" "путь\СП20.xlsb" "путь\ОСР-2016.xlsb"
```

```bash
python tools/verify_sources.py "путь\СП131...2025.xlsb" "путь\СП20.xlsb"
```

Первая команда пересоберёт CSV в папке `data`, вторая — сверит их с исходниками.
Затем загрузите новые файлы из `data` на GitHub (шаг «Как обновить приложение»).

## Частые вопросы

**Приложение «уснуло» и показывает экран с кнопкой.**
Бесплатные приложения засыпают, если их долго никто не открывал. Нажмите
**Yes, get this app back up!** — через 30–60 секунд оно снова работает. Данные не теряются.

**В журнале ошибка `ModuleNotFoundError`.**
Проверьте, что файл `requirements.txt` лежит в корне репозитория и называется именно так.

**Ошибка `FileNotFoundError: data/stations.csv`.**
Не загрузилась папка `data`. Загрузите её содержимое заново (шаг 3), сохранив имя папки `data`.

**Как удалить или остановить приложение.**
https://share.streamlit.io → у приложения нажмите **⋮** → **Delete**.

**Можно ли сделать приложение закрытым?**
Да: в настройках приложения на share.streamlit.io (**Settings → Sharing**) можно
ограничить доступ по почтовым адресам. По умолчанию — доступно всем по ссылке.

## Запуск на своём компьютере (без интернета)

1. Установите Python 3.12 с https://www.python.org/downloads/ (при установке отметьте
   **Add python.exe to PATH**).
2. Откройте папку `sp131-climate`, в адресной строке Проводника наберите `cmd` и нажмите Enter.
3. Выполните по очереди:

```bash
pip install -r requirements.txt
```

```bash
streamlit run app.py
```

Откроется браузер с приложением (адрес `http://localhost:8501`). Чтобы остановить —
закройте чёрное окно командной строки.
